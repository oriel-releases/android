# Oriel

A new wallpaper, every day. Oriel is a free Android app that sets a fresh, high-quality Unsplash
photo as your phone's wallpaper, the same one as on your computer.

**[Download Oriel for Android](https://github.com/oriel-releases/android/releases/latest/download/Oriel.apk)** · [Website](https://oriel.akbarjon.uz)

This repository hosts Oriel's releases. Installed copies update themselves from here.

Requires Android 8.0 or newer. Open Oriel.apk and, if Android asks, allow your browser to install apps.
Oriel is in beta.
